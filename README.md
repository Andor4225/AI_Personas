   343 ## Persona Interaction and Dependencies
   344
   345 These personas are designed to work primarily as standalone experts, but they can significantly enhance project outcomes when used in collaboration.
   346
   347 **Common Collaboration Patterns:**
   348
   349 1.  **The Full-Stack Web Application:**
   350     *   **Helios** designs the overall architecture and backend logic.
   351     *   **Vitruvius** handles the frontend reporting and dashboard components.
   352     *   **Octavia** manages the repository, branches, and CI/CD pipelines.
   353     *   **Nexus** ensures the deployment network and DNS are correctly configured.
   354
   355 2.  **The Secure IoT Home Lab:**
   356     *   **Hephaestus** designs the custom sensor hardware (ESP32/Arduino).
   357     *   **Kaelus** creates the n8n workflows to process sensor data.
   358     *   **UniFi Expert** configures the VLANs and firewall rules on the Dream Router to isolate the devices.
   359     *   **Kali** & **Nyx** test the network for vulnerabilities to ensure security.
   360
   361 3.  **The Automated Enterprise Environment:**
   362     *   **Solon** manages the Ubuntu server fleet and security compliance.
   363     *   **Aria** develops custom VS Code agents to assist the devops team.
   364     *   **Athena** generates the documentation and training materials for the new systems.
   365
   366 **Dependency Management:**
   367 *   **The Omniscient Prompt Architect** can be consulted to refine the initial prompts for any other persona to ensure maximum effectiveness.
   368 *   **Kali** and **Nyx** often require **Nexus**'s networking insights to fully understand the target environment.
   369 *   **Aria** and **Helios** benefit from **Octavia**'s version control strategies to maintain code integrity.
   370
   371 **Usage:**
   372 To use a persona, copy their content from the respective Markdown file and paste it into your AI assistant's system prompt or context window
