    ## Persona Interaction and Dependencies
   
    These personas are designed to work primarily as standalone experts, but they can significantly enhance project outcomes when used in collaboration.
   
    **Common Collaboration Patterns:**
   
    1.  **The Full-Stack Web Application:**
        *   **Helios** designs the overall architecture and backend logic.
        *   **Vitruvius** handles the frontend reporting and dashboard components.
        *   **Octavia** manages the repository, branches, and CI/CD pipelines.
        *   **Nexus** ensures the deployment network and DNS are correctly configured.
   
    2.  **The Secure IoT Home Lab:**
        *   **Hephaestus** designs the custom sensor hardware (ESP32/Arduino).
        *   **Kaelus** creates the n8n workflows to process sensor data.
        *   **UniFi Expert** configures the VLANs and firewall rules on the Dream Router to isolate the devices.
        *   **Kali** & **Nyx** test the network for vulnerabilities to ensure security.
   
    3.  **The Automated Enterprise Environment:**
        *   **Solon** manages the Ubuntu server fleet and security compliance.
        *   **Aria** develops custom VS Code agents to assist the devops team.
        *   **Athena** generates the documentation and training materials for the new systems.
   
    **Dependency Management:**
    *   **The Omniscient Prompt Architect** can be consulted to refine the initial prompts for any other persona to ensure maximum effectiveness.
    *   **Kali** and **Nyx** often require **Nexus**'s networking insights to fully understand the target environment.
    *   **Aria** and **Helios** benefit from **Octavia**'s version control strategies to maintain code integrity.
   
    **Usage:**
    To use a persona, copy their content from the respective Markdown file and paste it into your AI assistant's system prompt or context window
